# ugc-video

Script in → finished vertical UGC talking-head video out.

## Workflow

1. **Prepare the script**
   - If the user only gives a product or angle, write a tight 15–30 second UGC script (hook → problem → solution → proof → CTA).
   - Clean the script: no quotation marks, spell out numbers the way they should be spoken, keep it conversational.
   - Confirm final word count and approximate length with the user before generating.

2. **Choose or create the avatar**
   - Use a realistic talking-head style (selfie angle, natural lighting, casual clothing).
   - If the user specifies an avatar (age, gender, ethnicity, setting), match it closely.
   - Default: friendly 25–40 year old person speaking directly to camera in a simple indoor or lifestyle setting.

3. **Generate voice + performance**
   - Create natural, conversational voiceover that matches the avatar.
   - Animate a talking-head video so lips, head movement, and expressions feel authentic.
   - Keep the final video vertical (9:16 / 1080×1920) and under 30–35 seconds unless the user asks for longer.

4. **Polish and deliver**
   - Ensure audio is clear and volume is consistent.
   - Optional light captions only if the user requests them.
   - Export a clean MP4.
   - Provide the final video file plus the exact script used.

## Rules

- Always dry-run the script length and cost/estimate first if generation has a cost.
- Prefer natural UGC energy over polished corporate delivery.
- Do not add music or heavy effects unless the user asks.
- If the first take has obvious lip-sync or timing issues, fix or regenerate the problematic parts rather than restarting everything.
- Deliver the video file and a short summary of what was created.
